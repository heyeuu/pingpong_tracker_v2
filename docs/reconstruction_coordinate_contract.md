# 重建坐标与单位契约

## 1. 目标

本文档用于统一在线链路与离线回放中的 `t,x,y,z` 语义，避免单位和坐标系歧义。

## 2. 基本约定

- 时间单位：秒（`s`）
- 长度单位：米（`m`）
- 角度单位：弧度（`rad`）
- 时间戳：单条轨迹内必须严格递增，不允许倒退。

## 3. 世界坐标系（World Frame）

采用右手系，定义如下：

- 原点 `O_w`：球台中心点在台面上的投影点。
- `+X_w`：沿球台长度方向，从己方半台指向对方半台。
- `+Y_w`：沿球台宽度方向，面向对方球台时从左到右。
- `+Z_w`：垂直向上，台面高度定义为 `z = 0`。

所有回放 CSV 中的 `x,y,z` 均指世界坐标。

## 4. 相机坐标系（Camera Frame）

相机坐标系约定：

- 原点 `O_c`：相机光心。
- `+Z_c`：光轴正向（从相机指向场景）。
- `+X_c`：图像平面向右。
- `+Y_c`：图像平面向下。

相机与世界坐标变换采用：

`p_w = R_wc * p_c + t_wc`

其中 `R_wc` 为 3x3 旋转矩阵，`t_wc` 为 3x1 平移向量。

## 5. 单目重建最小假设（MVP）

单目路线先冻结如下先验：

- 已知内参：`fx, fy, cx, cy`
- 已知畸变参数：`k1, k2, p1, p2, k3`（可按需裁剪）
- 已知球半径：`r_ball = 0.02 m`
- 已知球台面高度：`table_height = 0.0 m`（世界系）
- 已知相机外参：`R_wc, t_wc`

基于检测结果 `Ball2D(center_u, center_v, radius_px)`：

1. 对 `center_u, center_v` 去畸变，得到归一化像面坐标 `(x_n, y_n)`。
2. 深度估计（先验驱动）：
   - `z_c = f_eff * r_ball / radius_px`
   - `f_eff = 0.5 * (fx + fy)`
3. 相机坐标恢复：
   - `x_c = x_n * z_c`
   - `y_c = y_n * z_c`
4. 变换到世界坐标：`p_w = R_wc * p_c + t_wc`。

当 `radius_px <= 0`、检测点越界或估计深度异常时，必须输出失败状态，不得写入伪观测。

## 6. CSV 契约

离线回放 CSV 最小列：

- `t`: 时间戳（秒）
- `x`: 世界坐标 x（米）
- `y`: 世界坐标 y（米）
- `z`: 世界坐标 z（米）

允许时间列别名（`time`, `timestamp`, `time_sec` 等），但语义必须与 `t` 等价。

## 7. 日志与可视化约定

- 在线日志中出现的三维位置默认均为世界坐标（米）。
- 若打印相机坐标，必须显式加后缀 `_cam`。
- 若打印像素坐标，必须显式加后缀 `_px`。

## 8. 验收检查

- 任意一条在线落盘 CSV 可直接被 `pingpong_tracker_predictor_replay` 消费。
- 团队成员在不同机器上复现实验时，不应出现单位/轴向解释分歧。
